# FocusPlay · 专注乐园 🎯

> **基于认知神经科学与 ADHD 临床实证范式构建的执行功能训练与专注支持系统。**
> 专为对抗低唤醒状态、时间盲（Time Blindness）、冲动控制困难与启动瘫痪（Task Paralysis）而设计。

🌐 **线上访问**：[focusplay.516278.xyz](https://focusplay.516278.xyz)

## 🌟 核心特性全览

### 1. 🌅 每日按需场景训练方案 (One-Tap Regimens)
无需复杂选择，针对 ADHD 一天内多巴胺与自律神经的生理节律，提供 4 大专属微步练习：
- **早起 · 生物钟与多巴胺唤醒**（约 5 分钟）：时间感知重现 + 舒尔特方格视觉扫描。
- **上午 · 冲刺抗分心与深度启动**（约 7 分钟）：Flanker 箭头抗干扰滤噪 + 5分钟微步专注冲刺。
- **下午 · 防走神与工作记忆重启**（约 6 分钟）：SART 持续警觉防神游 + Corsi 视空间记忆方块。
- **睡前 · 神经降温与解压**（约 5 分钟）：Go/No-Go 冲动急刹车 + **4-7-8 深度舒缓呼吸**。
- **全屏沉浸浮条**：底部专属控制岛，切出其他页面后一键 `[返回训练 ▶]` 秒级恢复。

### 2. 🧠 8 款临床实证认知训练矩阵 (Evidence-Based Games)

| 训练游戏 | 认知干预维度 | 循证科学依据 |
|---|---|---|
| **Eriksen Flanker<br>弗兰克抗干扰** | 选择性注意与冲突抑制 | 认知心理学抗干扰金标准（Eriksen, 1974; Mullane et al., 2009）。训练快速过滤视野杂讯，激活前扣带回（ACC）。 |
| **SART / CPT<br>持续注意警觉** | 持续警觉维持与防走神 | 临床经典 CPT（Robertson et al., 1997）。精准捕捉默认网络（DMN）侵入导致的走神，克制惯性敲击。 |
| **Corsi Block<br>科西记忆方块** | 视空间工作记忆容量 | 经典 Cogmed 核心测验（Corsi, 1972; Klingberg et al., 2005）。正序与逆序倒背，强化视空间写字板信息操纵力。 |
| **Time Sense<br>时间感知校准** | 时间盲对抗与生物钟重校 | Russell Barkley 博士时间近视模型。体会目标时长并凭内源感知长按重现，微秒级校准多巴胺生物钟。 |
| **Dual N-Back<br>双通道工作记忆** | 动态工作记忆刷新 | Jaeggi et al. (2008)。空间位置与听觉字母双通道独立追踪，多步前瞻强化前额叶信息流更新。 |
| **Go / No-Go<br>冲动急刹车** | 反应抑制与运动刹车 | Logan & Cowan (1984); Aron et al. 运动皮层刹车回路。锻炼右侧额下回紧急制动，减少脱口而出与误触。 |
| **Schulte Grid<br>舒尔特方格** | 周边视野注意广度 | 临床注意分配经典工具。视觉扫视数字快速定位，提升搜索效率。 |
| **Stroop<br>字色冲突灵活性** | 语言反射抑制与认知灵活性 | Stroop (1935)。忽略字义选择墨水颜色，锻炼大脑在相互干扰规则下的自如切换。 |

### 3. ⏱️ Time Timer 动态视觉表盘与全屏 Zen 沉浸
- **Time Timer 动态弧面圆盘**：用肉眼可见的色彩弧面缩减消除抽象时间焦虑，一眼看清时间流逝。
- **抗启动瘫痪阶梯**：专为克服任务启动瘫痪设计的 5 分钟微步（Micro-Pomodoro）、15分钟冲刺、25分钟番茄与45分钟心流。
- **全屏 Zen 沉浸模式**：一键隐藏干扰元素，支持 `Esc` 或双击安全退出，配合暖心颂钵钟鸣。
- **全局底栏倒计时药丸**：后台计时进行中，底栏控制中枢优雅呈现呼吸光点与分秒倒计时，点击一键直达。

---

### 4. 🎧 双引擎白噪音与多源声场
- **5 款纯本地原生算法音源（0延迟、免翻墙、100% 离线稳定）**：
  - 🌊 **原生褐噪音**：布朗运动低通积分滤波，如温和低沉的深海瀑布；
  - 🌧️ **原生粉红噪音**：1/f 平衡频谱自然雨声，平抑焦躁；
  - 🍃 **原生绿噪音**：森林微风与潺潺溪流波动；
  - 🛡️ **原生纯白噪**：全频段均衡滤波，阻断办公室/室内突发环境杂音；
  - ⚡ **原生 40Hz 伽马脑波**：双耳节拍神经共振，激活前额叶专注回路。
- **YouTube 精选流与自定义音源**：内置 8 小时深层褐噪、雨夜雷鸣、咖啡馆陪伴效应、Lofi Girl，支持粘贴任意 YouTube 链接；支持异常与超时自动降级至本地音效。

---

### 5. 🌬️ 正念呼吸 · 神经重启
- **三种经典临床呼吸节律**：
  - 箱式呼吸（4-4-4-4，海豹突击队战术平定）；
  - **4-7-8 深度舒缓呼吸**（4s 吸气、7s 屏气、8s 呼气，Dr. Andrew Weil 助眠降温法）；
  - 4-6 舒缓平定。
- **录音级温润人声音频引导**：
  - 摒弃生硬的 Web Speech API，采用预置温润自然女声音频切片（`audio/breathe/*.mp3`），放缓 15% 沉静节奏；
  - 支持独立开闭，闭眼呼吸体验如专业冥想软件。

## 🛠️ 技术架构

- **纯原生 Web 前端**：ES Modules 架构，零构建工具链依赖，秒级加载。
- **Web Audio 实时合成引擎**：纯原生算法合成提示音与无损白噪音，零外链音频广告阻碍。
- **跨设备云同步**：支持通过个性化同步码无缝同步训练时长、连击天数与各关卡成绩。
- **全端响应式设计**：专为 iPhone、iPad、Android、Mac 及宽屏 PC 全面适配触控与安全视区。
